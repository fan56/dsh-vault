# 每机器只留最新快照，覆盖式写入

Vault 中每台机器的目录里只有一个快照文件，新备份直接覆盖旧快照，不保留历史版本。备份工具通常带历史，这里刻意不带：用户在「历史近乎免费」（配置级负载仅 KB 量级）与「仓库整洁 + restore 永远拉当前这份的单一语义」之间选了后者。

## Considered Options

- 时间戳快照 + 保留上限（推荐被否）：有回退能力，但快照与选择器都变复杂。
- latest + 每日留档：折中方案，逻辑复杂度不值得。

## Consequences

- 「改坏配置之后才跑的那次备份」无法回退——backup 前做本地可解密性自检（加密后立即试解密）因此更重要。
- 未来若要加历史，需同时改快照格式与 restore 选择器，属于格式级变更。
