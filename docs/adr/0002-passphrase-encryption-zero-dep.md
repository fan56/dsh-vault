# 口令派生密钥，整包加密，零依赖

快照在离开本机前整体加密：用户口令经 scrypt 派生密钥，AES-256-GCM 认证加密，密文自带格式版本号（vault format v1）。只用 Node 内置 `crypto`，不引入任何 npm 依赖（本生态已拍板插件零依赖）。口令默认每次 backup/restore 询问，不落盘；「记住口令」为可选功能，仅存本机（macOS Keychain），且只用于免输——不改变「口令只在用户手里」的信任模型。

GitHub 私有仓库只是第一道门（账号被盗、token 泄露），加密才是数据本身的门。选口令而非密钥文件，是因为迁移时人类只须「记得口令」，无须人肉搬运文件——与「新机器一条命令拉平」直接冲突的方案一律不选。

## Considered Options

- 随机密钥文件：加密强度更高，但新机器要多一步安全搬运密钥文件，违背迁移目标。
- 仅靠 private repo + GitHub token：用户明确要求数据加密，只作对照。

## Consequences

- 口令遗忘 = 快照永久不可解，插件不做任何找回机制；backup 时应提示口令强度。
- 加密格式带版本号，未来换算法（如 Argon2）走格式升级而非原地替换。
